# leek16

leek16 is a 16-bit ISA. In this repository you will find

- **[Leek Emulator](crates/emulator)**: a leek16 emulator
- **[Leek Assembler](crates/assembler)**: a Leek lang compiler.

You can find the ISA specification in the [ISA](ISA) file.

**TL;DR** I didnt pay attention in my Programming language concepts class nor my computer architecture, so this is to learn how things work more "under the hood" i guess.
